HOME PAGE SEO IMAGE PACK

This pack contains 16 SEO-named WebP copies of the supplied homepage images.
The visual content and pixel dimensions are preserved; the files are re-encoded for substantially smaller web delivery.

SECTIONS
1-hero-section/                 -> Hero Section
2-categories-4-images/          -> Four Category Showcase
3-sub-categories-6-images/      -> Six Subcategory Showcase
4-our-services-images/          -> Our Services

IMPORTANT
- These are source assets for implementation; do not blindly overwrite existing website assets.
- Before implementation, inspect the actual repository image paths and existing component imports.
- Recommended component references are documented in home-page-image-map.json.
- The component names are based on the current project reports and should be verified in the repository before editing.
- Do not change layout, animation, dimensions, or section structure when replacing the images.
